# Python - Async

This project introduces asynchronous programming in Python using `async` and `await`.

## Learning Objectives

- Understand asynchronous functions and coroutines.
- Use `asyncio` to execute asynchronous code.
- Generate random delays using the `random` module.
- Use `asyncio.sleep()` to wait without blocking other coroutines.

## Tasks

### 0. The Basics of Async

**File:** `0-basic_async_syntax.py`

Implements an asynchronous coroutine named `wait_random` that waits for a random delay between `0` and `max_delay` seconds and returns the delay.

## Requirements

- Python 3.8
- All functions and coroutines must have type annotations.
- All modules and functions must have documentation.
- Code must follow Pycodestyle.
