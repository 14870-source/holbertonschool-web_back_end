# Python - Async Comprehension

This project introduces asynchronous generators and asynchronous comprehensions in Python.

## Learning Objectives

- Understand asynchronous generators.
- Use `async` and `await`.
- Use asynchronous iteration with `async for`.
- Generate random floating-point numbers using the `random` module.
- Add type annotations to asynchronous generators.

## Tasks

### 0. Async Generator

**File:** `0-async_generator.py`

Implements an asynchronous generator that waits one second and yields a random floating-point number between 0 and 10, repeating the process ten times.

## Requirements

- Python 3.8
- Pycodestyle 2.5.x
- All functions must be type-annotated and documented.
