# Advanced HTML

## Description
This project introduces the fundamentals of HTML5 and teaches how to structure web pages using HTML elements and semantic tags.

## Learning Objectives
- Understand HTML5 structure.
- Create a basic HTML page.
- Use semantic HTML elements.
- Work with headings, lists, tables, and links.
- Embed images, audio, and video.
- Follow W3C HTML standards.

## Requirements
- HTML5
- W3C-compliant code
- No CSS or JavaScript
